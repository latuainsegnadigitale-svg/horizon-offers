COSA C'È IN QUESTA CARTELLA
  public/          il sito (index.html, logo, icone, ecc.)
  wrangler.jsonc   le impostazioni per Cloudflare (non serve modificarle)

PUBBLICARE SU CLOUDFLARE (con GitHub, come Horizon CRM)
  1) GITHUB
     - Repository horizon-offers (se esiste già: "Add file" > "Upload files" e trascina il contenuto di questa
       cartella sopra i file vecchi; se non esiste: "+" > "New repository" > nome horizon-offers > Private).
     - Trascina TUTTO il contenuto di questa cartella in un colpo solo: wrangler.jsonc e la cartella public.
     - Se nel repository ci sono ancora netlify.toml o la cartella netlify, puoi cancellarli: non servono più.
     - "Commit changes".
  2) CLOUDFLARE
     - Workers & Pages > Create > "Import a repository" > GitHub > scegli horizon-offers.
     - Project name: horizon-offers  (deve essere uguale al nome scritto in wrangler.jsonc).
     - Build command: lascia vuoto. Deploy command: npx wrangler deploy (è già quello proposto).
     - "Deploy". L'indirizzo diventa  horizon-offers.tolvepaolo6.workers.dev
     - Questo sito non ha chiavi da inserire.
  3) AGGIORNAMENTI
     - Ogni volta che carichi file nuovi su GitHub, Cloudflare ripubblica da solo. Niente crediti.
  4) NETLIFY
     - Quando il sito su Cloudflare funziona, su Netlify elimina (o scollega da GitHub) il vecchio sito,
       altrimenti a ogni caricamento su GitHub Netlify ripubblica e consuma crediti.
  5) SUL TELEFONO
     - Apri il nuovo indirizzo, poi "Aggiungi a schermata Home". I lavori salvati con il vecchio indirizzo
       restano lì: prima di cambiare, scarica i video che ti servono.

COLLEGAMENTO DA HORIZON RENDER
  Il tasto "Passa a Horizon Offers" di Horizon Render apre questo sito con le misure già inserite:
  per questo il progetto su Cloudflare deve chiamarsi esattamente horizon-offers.
